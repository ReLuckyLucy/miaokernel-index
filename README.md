## 启动项目

需要安装 Node.js `22.13.0` 或更高版本。

```bash
npm install
```

macOS / Linux：

```bash
npm run dev
```

Windows PowerShell：

```powershell
$env:WRANGLER_LOG_PATH = ".wrangler/wrangler.log"
npx vinext dev
```

启动后访问：`http://localhost:3000/`
