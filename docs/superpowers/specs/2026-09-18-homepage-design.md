# 渺核科技首页设计

## 已确认内容
企业名称：渺核科技。Slogan：渺见未来，核聚价值。
项目：GDMU-NA TokenHub，大模型网关。
项目入口：https://tokenhub-tunnel.apps.gdmuna.com/
标记：用户提供的 SVG，保持原有几何与色彩。

## 视觉与结构
以 Kimi 招聘站为风格参考：黑白灰、点阵文字、像素宇宙、逐屏叙事与 ASCII 转场。独立编写代码与程序化图形，不移植参考网站的源代码、字体、背景图片或招聘内容。
四个全屏场景：品牌首页、关于渺核、项目实践、探索未来。桌面端大留白，移动端顺序重排。使用原生滚动与 scroll-snap，保留缩放、键盘和无 JavaScript 阅读能力。
首页将上传原子标记转译为程序化像素核体；细微字符雨常驻背景，转场时字符雨增强。

## 内容边界
只有名称、口号、项目名称、定位及网址属于已提供事实。其余描述为品牌文案建议，不提供成立时间、团队规模、客户、价格、模型兼容性、API 路径、SLA 或性能数字。项目终端明确为概念演示，不访问真实接口。未提供联系方式，不设置假邮箱或无法提交的联系表单。

## 技术与交付
零运行时依赖 HTML/CSS/JavaScript；Canvas 2D；独立 CSS 与模块职责拆分。点阵标题使用矢量图形，不打包字体文件。可双击打开，另外提供零依赖 Node 静态服务器。源文件工程及内联单 HTML 均交付。

## 验收
Node 内置测试检查确定性数学函数、可信项目配置、锚点和安全外链。Playwright 检查桌面与移动布局、导航、暂停、代码雨切换、复制入口、弹层、减少动态效果、无脚本降级、无控制台异常。单文件已内嵌全部资源；本环境浏览器限制 file/HTTP 地址导航，因此浏览器验收采用内存注入，未验证 file 协议导航或公开部署。截图只代表实际浏览器渲染，不代表逐帧还原原站。
