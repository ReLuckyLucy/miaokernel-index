# 验证记录

验证日期：2026-09-18。

## 本地环境

Node.js v22.16.0；系统 Chromium 144.0.7559.96；Python Playwright。页面运行时不需要 Python、Playwright、第三方 JavaScript 库或外部字体服务。

## 构建与单元测试

`npm run build` 成功，输出约 84 KB 的 `dist/index.html`，CSS、JS 和所有视觉 SVG 资源均内嵌。

`npm test`：5 项通过、0 项失败。覆盖数值边界处理、可复现随机序列、场景索引边界、用户提供的项目名称与网址，以及四个唯一场景和安全外链。

## 浏览器验收

命令：`python tests/browser.py --screenshots /mnt/data/miaohe-previews`。

检查的视口：1440×900、1024×768、768×1024、390×844、320×740。均未检测到横向页面溢出。

桌面端完成图片加载、页面标题、场景导航、Canvas 可用性、动效暂停、代码雨状态切换、项目弹窗、Escape 关闭及复制反馈检查。暂停后读取 Canvas 图像，间隔 250 ms 再次读取，确认画布停止变化。

窄屏完成菜单展开、导航到项目区及菜单关闭检查。系统 reduced-motion 设置下为静态画面，动效启用按钮禁用。禁用 JavaScript 时标题和项目入口仍可访问。页面未捕获到 JavaScript 执行错误。

截图经过人工目视检查，并修正了英文点阵基线和球体下方标注间距。

### 验收方式与限制

此环境的浏览器管理策略阻止本地文件和 HTTP 地址导航。没有修改或绕过策略；使用 `page.set_content` 在独立 Chromium 页面内注入已经内联的 HTML 来检查渲染和交互。因此以上结果**不等价于在 file 协议、用户电脑或公开域名上的端到端验证**。

复制测试只确认交互完成后给出准确的成功或失败提示；复制本身受浏览器权限影响。外部 TokenHub 链接没有被自动打开，未验证网关可用性、实际功能或后台接口。

## 本地静态服务器检查

单独通过本地 HTTP 客户端访问 `server.mjs`，检查如下：

- 首页、CSS、用户 SVG、内联版页面：HTTP 200。
- HEAD 请求返回 200 且响应体为空。
- 不存在的文件返回 404。
- POST 返回 405。
- 编码后的上级路径访问返回 403。

用户 SVG 与原上传内容逐字节相同。详见 `server-test-report.json`。上述检查仅针对本地预览服务器，不是完整安全审计。
